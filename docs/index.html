Overview

From black-box trajectory beliefs to a single safe plan

Private models

Each agent runs a different learned predictor, with a different latent dimension and architecture.

Joint future beliefs

Every model emits sampled joint trajectories in a common physical coordinate frame.

Wasserstein consensus

Agents fuse the empirical measures with an entropic barycenter and agree on one deterministic plan.

Safe execution

A shared selection criterion resolves conflicts, preserves temporal consistency, and respects safety margins.

Mathematical architecture

Core formulation

\[\nu^\star \in \arg\min_{\nu \in \mathcal{P}_2(\mathcal{M})} \sum_{i=1}^{M} \alpha_i W_2^2(\mu_i, \nu)\]

Each agent maintains a predictive empirical measure over joint futures in a common space \(\mathcal{M}\), where the latent dimension is irrelevant once the prediction is expressed in physical coordinates.

\[\mu_i = \frac{1}{N}\sum_{n=1}^{N} \delta_{x_i^{(n)}}, \quad x_i^{(n)} \in (\mathbb{R}^2)^{H \times M}\]

Each atom is a complete joint trajectory hypothesis, including the motion of all agents in the scene.

\[P_{ab}^{\star} = \exp\left(\frac{f_a + g_b - \widetilde{C}_{ab}}{\varepsilon}\right)\]

The barycentric consensus is solved with entropy-regularized optimal transport and the Sinkhorn updates in the dual domain.
