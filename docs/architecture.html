System design

Mathematical architecture and flow design

The system is built around a single idea: each agent predicts a physical joint future, not a latent embedding, and all agents fuse those predictions in a common measure space.

1. Observation

Agent $i$ receives a local observation $o_t^i$ and its own route context.

2. World-model rollouts

Model $\mathcal{W}_i$ produces $N$ joint rollouts in the physical trajectory space $\mathcal{M}$.

3. Empirical measure

These are compressed into $\mu_i = \frac{1}{N} \sum_n \delta_{x_i^{(n)}}$.

4. Broadcast

Agents exchange trajectory samples and trust weights without sharing model parameters or latents.

5. Entropic barycenter

The common belief is the minimiser of $\sum_i \alpha_i W_2^2(\mu_i, \nu)$.

6. Deterministic selector

Every agent scores the barycenter atoms with the same shared objective and picks the minimiser.

7. MPC tracking

Each agent tracks the selected plan with a receding-horizon primitive controller.

Engineering interpretation

  • Latent-space heterogeneity is treated as a non-issue because the shared object is the physical trajectory measure.
  • Consensus is reached by deterministic fusion; no negotiation, no optimisation over hidden weights, no gradient exchange.
  • The communication payload scales with the number of sampled trajectories, not with model parameter count.
